# 聊天搜索 · 正文与状态栏

这是一个 SillyTavern 前端扩展。默认搜索当前打开的单人聊天，也可以切换到当前角色的全部历史聊天。关键词支持中文、英文和数字；多个词用空格分开，须同时出现。结果只显示对话内容，不显示聊天文件名或发送日期。点击“展开对话”，在独立界面阅读这条消息和邻近对话，不跳转主聊天。

通过 GitHub 安装：在酒馆打开“扩展 → 安装扩展”，粘贴 `https://github.com/elviswang0510-stack/SillyTavern-Chat-Search` 并安装；之后在扩展管理中确认“聊天搜索 · 正文与状态栏”已启用。仓库根目录直接包含 `manifest.json`，不需要构建或安装额外依赖。后续更新可在酒馆的扩展管理中操作。

本地安装：把压缩包解压，将整个 `st-chat-search` 文件夹放到实际安装的 `SillyTavern/public/scripts/extensions/third-party/` 目录；最终应存在 `SillyTavern/public/scripts/extensions/third-party/st-chat-search/manifest.json`。也可以只为当前账户安装，放到 `SillyTavern/data/<用户目录名>/extensions/st-chat-search/`。刷新酒馆页面，必要时重启酒馆服务。“安装扩展”输入框接收 Git 仓库地址，不能直接填 ZIP。如果已经用文件夹方式安装，先删除旧的手动安装目录，再从仓库安装，以免重复加载。

打开角色聊天后，点击输入框左下角的三横线菜单或魔法棒菜单，两处都有“搜索当前聊天”快捷入口；也可以在扩展设置的“聊天搜索 · 正文与状态栏”里点击“打开聊天搜索”。输入关键词并点击“搜索”，用“范围”“内容”“发言人”缩小结果。默认搜索这个对话框的全部消息，包括未在主窗口展开的早期消息。搜索结果每批显示 40 条。

点击任意结果的“展开对话”，可以上下滑动阅读完整正文和状态栏，也可以切换“仅正文”。阅读界面从命中消息附近展开，点击“再看前面 20 条”或“再看后面 20 条”继续读。点“返回结果”保留原搜索结果和滚动位置；Escape 优先返回结果，再按一次关闭搜索。没有自动跳回原聊天、切换历史文件或保存聊天的操作。

搜索仅读取聊天消息的 `mes` 文本，不检索预设文件、角色设定、世界书、聊天元数据、`extra` 思考字段或未选中的重生成版本。系统消息、HTML 注释、脚本、样式、隐藏元素，以及常见的 `think`、`thinking`、`analysis`、`reasoning`、`system`、`prompt`、`preset`、`instructions`、`预设`、`提示词` 标签内容会被排除。它不会调用模型，也不向第三方上传聊天。搜索和独立阅读只读，不修改主聊天。

状态栏默认识别 `<status>…</status>`、`<statusbar>…</statusbar>`、`<状态栏>…</状态栏>`、常见的状态栏 HTML 类名、标题包含“状态”或“status”的 `<details>`，以及 `【状态栏】` 等文字标记。其他标签可在“内容识别设置”中填写。例如状态使用 `<sheet>…</sheet>`，把 `sheet` 加入状态栏标签。无法识别分类的普通文字仍可用“正文和状态栏”一起搜索。被 HTML 转义后显示的标签会作为普通文字处理。

独立插件、酒馆助手或 JavaScript 实时计算后生成、且没有存入消息正文的状态栏，本版无法直接读取。它也无法凭语义识别已经混进正文、没有任何标记的预设文字。遇到这种格式，需要按实际消息结构补充识别规则。当前只支持单人角色的历史聊天，群聊会提示先选择角色。

当前聊天搜索和阅读直接使用酒馆已载入的数据，不逐层触发“加载更多”，也不请求其他聊天文件。清理后的正文会暂存于当前页面内，后续搜索可复用；内容或识别设置变化时会更新缓存，缓存有容量上限。搜索会定期让出主线程，阅读窗口最多同时挂载 60 条消息。实际耗时仍取决于手机性能和消息长度，不能保证任意大小的聊天都没有延迟。

没有历史文件时仍能搜索当前聊天；切换到全部历史时，若酒馆返回历史列表不可用，会明确提示本次只搜索了当前聊天。部分文件读取失败也会提示结果不完整。消息编辑、删除、切换重生成版本或切换角色后，旧结果会清除，请重新搜索。

本版按照 [SillyTavern 官方扩展接口](https://docs.sillytavern.app/for-contributors/writing-extensions/) 和官方 release 源码的菜单、历史读取方式实现。在合成环境验证功能与长聊天行为，并检查手机和桌面显示；尚未在你的实际酒馆版本与状态栏格式中验证。删除插件文件夹并刷新页面即可卸载。
